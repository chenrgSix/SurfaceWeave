# 说一句，界面就变

这个实验室把“随时改变 UI”直接放到眼前：左边是对话，右边是一整个可操作的应用。点击预设对话，观察主题、导航、布局和组件同时变化。

![对话式应用实验室](/conversation-playground.png)

## 开始体验

在仓库根目录运行 `pnpm install --frozen-lockfile`，然后 `pnpm dev`。使用 Node 22。默认地址是 `http://127.0.0.1:5175`，无需 API Key 或后台。

先在右边填写一句交接备注，然后按这个顺序发送：

1. **午夜紫**：整个页面换色，包含菜单、指标、图表和表单。
2. **菜单到顶部**：左侧导航移到上方，内容区重新铺开。
3. **表单变决策卡**：选择框变成业务对比卡，审批前置，数据保留。
4. **打开双视图**：两个独立的 Renderer 同时编辑同一份 Surface 数据。
5. **变成简报**：暖色主题、顶部导航、单栏内容、完整概览一起改变。
6. **撤销上一条**：恢复刚才的界面结构，保留最新输入。

## 十条对话模板

| 模板            | 实际操作                                              |
| --------------- | ----------------------------------------------------- |
| 午夜紫 / 薄荷绿 | 对页面根节点 `setProps`，选择可信主题枚举             |
| 菜单到顶部      | `moveNode` 把导航移入正文容器，更新导航布局枚举       |
| 表单变决策卡    | `replaceComponent`、`groupNodes`、`moveNode` 原子批次 |
| 进入专注模式    | 隐藏概览、指标和额外视图，保留编辑工作台              |
| 打开双视图      | 显示第二视图并应用双栏 LayoutSpec；窄屏降级为单栏     |
| 工作台置顶      | 把实际工作台节点移到内容区第一位                      |
| 变成简报        | 主题、导航、可见性和节点顺序在同一批次变更            |
| 紧凑布局        | 减少间距、切换密度令牌并显示运行时事件                |
| 恢复页面布局    | 恢复初始页面树，业务表单和数据不重置                  |

可以直接点击模板，也可以在输入框提交模板原句或短名称。未知文字会明确提示尚未连接语言模型，不会被猜测执行。

## 哪些变化由运行时负责

页面外壳 `live-application` 与业务表单 `incident-recovery` 都是实际 Surface，使用同一个 Store 和注册组件体系。外壳包含导航、标题、概览、指标、工作台、共享视图与事件面板。

- 对话产生的语义操作调用真实 `AgentUIToolRuntime`，经过 schema 与 revision 校验后写入 Store。
- 主题、导航方向和密度只能从注册组件允许的枚举中选择。对应 CSS 由本地可信 React Pack 提供；Wire 中不接受任意 CSS、DOM 或 JavaScript。
- 每条成功变更保留界面快照。撤销使用当前 `data`，只恢复旧结构；不会覆盖撤销前刚刚编辑的数据。
- 页面外壳的变更不修改业务确认快照。业务表单正在确认或执行时，禁止通过对话重组表单结构。

对话控制区与浏览器式预览边框属于演示宿主，保持固定，让应用变化有稳定的参照。右侧应用内部的页面外壳、表单、确认与结果均由 SDK 渲染。

## 边界

这是固定对话映射，**没有 LLM 推理**。业务数据与外部执行是模拟的，状态共享限于同页同一个 Store。撤销最多 40 步、对话最多 80 条，仅存在当前会话内存，不是持久审计或跨设备协作系统。

点击右上角「业务流程案例」可以进入[原始供应链指挥台](./operations-center)，检查硬约束、过期写入、确认快照和安全重试。

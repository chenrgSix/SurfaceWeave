# 供应链异常处置指挥台

这个 demo 展示 SurfaceWeave 的核心价值：**Agent 可以改变业务界面的结构，运行时保留用户数据、执行约束，并把业务执行交还给人和宿主。**

它不是主题切换器，也不依赖真实 LLM。虚构案例是一批关键 MCU 延误，运营人员需要为八条产线选择恢复方案。

![供应链异常处置指挥台](/operations-center.png)

## 本地启动

```bash
nvm use 22
pnpm install --frozen-lockfile
pnpm dev
```

默认打开[对话式实验室](./conversation-playground)。点击右上角「业务流程案例」，或访问 `http://127.0.0.1:5175/?demo=operations`，进入本页描述的原始指挥台。启动命令先构建所需 SDK，页面不需要 API Key 或后端。原茶叶验收例保留为 `pnpm dev:tea`，Tauri 入口不变。

## 按这个顺序体验

| 动作                   | 可观察的实际能力                                                      |
| ---------------------- | --------------------------------------------------------------------- |
| 生成处置工作台         | `ui.createToolSurface` 从注册的 Tool Schema 生成字段和数据绑定        |
| 修改备注，打开共享视图 | 两个 `SurfaceRenderer` 使用同一 `surfaceId` 与 Store，双向同步        |
| 重组为决策界面         | 下拉框替换为业务方案卡，审批区前置，4 个操作原子应用，输入保留        |
| 隐藏强制审批           | 注册工具的硬约束拒绝整批操作，包括批次中的合法修改                    |
| 发送过期版本           | `baseRevision` 不匹配，当前 Surface 不变                              |
| 审批后提交             | 生成确认 Surface，宿主请求数仍为 0                                    |
| 返回修改，再次确认     | 必须重新确认新快照，不能复用旧确认执行新参数                          |
| 确认执行、失败、重试   | 模拟 Host 首次失败；使用原参数与原幂等键重试，结果由独立 Surface 展示 |

![重组后的业务组件与共享视图](/operations-center-workspace.png)

展开页面底部的运行时事件可查看实际工具错误码、revision 和调用信息。记录保留最近 40 条；重置会清理订阅、计时器和演示内存。

## 架构与边界

```text
脚本化 Agent → AgentUIToolRuntime → SurfaceStore → 两个 SurfaceRenderer
                     ↓                     ↑
             注册工具 / 硬约束          用户编辑 / 语义操作

ActionIntent → ToolToUIRuntime → 确认快照 → 模拟 Host → 结果 Surface
```

- **真实 SDK：** Schema 生成、组件注册与解析、数据绑定、原子操作、约束与版本校验、确认快照、调用状态和安全重试。
- **模拟业务：** 物流数据、成本与时效估算、Agent 决策、承运商 API 与运单。本例没有远程模型推理或真实订单写入。
- **同步范围：** 同一页面共享同一个内存 Store，不代表跨设备多人协作。
- **宿主职责：** 顶部事件图、指标与 Copilot 导航由宿主实现；表单、决策组件、确认和结果由 SDK 渲染。真实系统还需要服务端鉴权、幂等持久化、业务后台和模型适配。
- **协议兼容：** 无 Core/Wire/ActionIntent 结构变更。业务组件和流程都留在 `examples/operations-center`。

## 验证

本例的 Vitest 场景测试覆盖：用户输入跨组件重组保留、整批越权回滚、过期版本拒绝、修改后的旧确认拒绝、重复提交去重、原幂等键和参数重试、销毁时取消模拟任务。

浏览器验收需要覆盖完整确认与重试流程、双视图输入、移动宽度布局和键盘对话框操作。单元测试不能代替真实浏览器验收，浏览器演示也不代表生产后端验收。

完整演示脚本及源文件说明见仓库中的 `examples/operations-center/README.md`。

# @package-first/component-pack-react-aria

React Aria runtime bindings for the framework-neutral Dynamic UI Component Pack
Protocol.

```sh
npm install react react-dom react-aria-components @package-first/core@next @package-first/renderer-react@next @package-first/component-pack-react-aria@next
```

Import `@package-first/component-pack-react-aria/styles.css` once in the host.

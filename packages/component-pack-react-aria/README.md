# @surfaceweave/react-aria

React Aria runtime bindings for the framework-neutral Dynamic UI Component Pack
Protocol.

```sh
npm install react react-dom react-aria-components @surfaceweave/core@next @surfaceweave/react@next @surfaceweave/react-aria@next
```

Import `@surfaceweave/react-aria/styles.css` once in the host.

The RC.4 candidate applies the shared Semantic LayoutSpec to Form, Stack, Grid,
Section, and Accordion without adding React Aria properties to the Surface.
